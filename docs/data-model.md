# Data model

PostgreSQL 16. Migrations are numbered SQL files under
`packages/database/migrations` run by `node-pg-migrate` (ADR-0005). This
document is the design; the first migration must match it and later changes
update both.

## Conventions

- Primary keys are `uuid` generated by the application (`crypto.randomUUID()`),
  so IDs exist before the row is written and can be used in idempotency keys.
- Every tenant-owned table has `tenant_id uuid NOT NULL REFERENCES tenants(id)`
  as its second column and an index that starts with `tenant_id`.
- Child rows reference parents with composite foreign keys that include
  `tenant_id`, so a row cannot point at a parent in another tenant.
- Timestamps are `timestamptz`; `created_at` and `updated_at` are set by the
  application, `updated_at` also by a trigger.
- Enumerations are `text` columns with `CHECK` constraints (cheaper to evolve
  than PostgreSQL enums).
- No column ever contains plaintext credentials. Credential columns hold a
  `secret_ref` (uuid into `secrets`) or a SHA-256 hash for bearer tokens ATLAS
  only needs to verify.
- Row-level security is enabled on every tenant-owned table. The application
  role is not `BYPASSRLS`; `withTenantTransaction` runs
  `SET LOCAL app.tenant_id = '<uuid>'`. Platform-scoped operations use a
  separate role-less path that only touches platform tables.

Two contexts exist in code:

```ts
type TenantContext = { tenantId: string; actor: Actor };      // dashboard, jobs for one tenant
type PlatformContext = { actor: Actor };                       // gateway pre-resolution, operator, jobs
type RuntimeContext = { tenantId: string; runtimeId: string }; // runtime bearer auth
```

## Tables

### tenants

```sql
CREATE TABLE tenants (
  id                  uuid PRIMARY KEY,
  slug                text NOT NULL UNIQUE,
  display_name        text NOT NULL,
  status              text NOT NULL CHECK (status IN ('provisioning','active','suspended','deleting','deleted')),
  slack_team_id       text NOT NULL,
  slack_enterprise_id text,
  suspended_reason    text,
  deletion_requested_at timestamptz,
  purge_after         timestamptz,
  created_at          timestamptz NOT NULL,
  updated_at          timestamptz NOT NULL
);
CREATE UNIQUE INDEX tenants_slack_identity ON tenants (slack_team_id, COALESCE(slack_enterprise_id, ''));
```

`slug` is generated from the Slack team domain with a random suffix and is
only a URL handle. `status` transitions:
`provisioning -> active`, `active <-> suspended`, `active|suspended ->
deleting -> deleted`.

### members

```sql
CREATE TABLE members (
  id             uuid PRIMARY KEY,
  tenant_id      uuid NOT NULL REFERENCES tenants(id),
  slack_user_id  text NOT NULL,
  display_name   text NOT NULL,
  email          text,
  role           text NOT NULL CHECK (role IN ('owner','admin','member')),
  status         text NOT NULL CHECK (status IN ('active','disabled')),
  last_login_at  timestamptz,
  created_at     timestamptz NOT NULL,
  updated_at     timestamptz NOT NULL,
  UNIQUE (tenant_id, slack_user_id),
  UNIQUE (tenant_id, id)
);
```

Invariant enforced in the repository: at least one active `owner` per active
tenant; the last owner cannot be demoted or disabled.

### slack_installations

```sql
CREATE TABLE slack_installations (
  id                     uuid PRIMARY KEY,
  tenant_id              uuid NOT NULL REFERENCES tenants(id),
  team_id                text NOT NULL,
  enterprise_id          text,
  team_name              text NOT NULL,
  app_id                 text NOT NULL,
  bot_user_id            text NOT NULL,
  bot_token_secret_ref   uuid NOT NULL,           -- secrets.id, encrypted xoxb token
  bot_scopes             text[] NOT NULL,
  installer_slack_user_id text NOT NULL,
  installer_member_id    uuid,
  token_type             text NOT NULL DEFAULT 'bot',
  installed_at           timestamptz NOT NULL,
  revoked_at             timestamptz,
  revoked_reason         text,
  created_at             timestamptz NOT NULL,
  updated_at             timestamptz NOT NULL,
  UNIQUE (team_id),
  FOREIGN KEY (tenant_id, installer_member_id) REFERENCES members (tenant_id, id)
);
CREATE INDEX slack_installations_tenant ON slack_installations (tenant_id);
```

One active installation per workspace. Reinstall updates the row in place and
rotates `bot_token_secret_ref`; the previous secret is marked retired.
`app_uninstalled` and `tokens_revoked` events set `revoked_at`. The gateway
requires `revoked_at IS NULL`.

### oauth_states

Platform-scoped (no tenant yet at install time).

```sql
CREATE TABLE oauth_states (
  id             uuid PRIMARY KEY,
  purpose        text NOT NULL CHECK (purpose IN ('install','login')),
  state_hash     text NOT NULL UNIQUE,      -- sha256 of the state value sent to Slack
  browser_nonce_hash text NOT NULL,         -- sha256 of the value in the short-lived cookie
  oidc_nonce     text,                      -- login only, compared to id_token nonce
  pkce_verifier_secret_ref uuid,            -- login only
  return_to      text,                      -- validated relative path
  expected_tenant_id uuid,                  -- login from a tenant page binds to that tenant
  created_at     timestamptz NOT NULL,
  expires_at     timestamptz NOT NULL,
  consumed_at    timestamptz
);
```

Consumption is `UPDATE ... SET consumed_at = now() WHERE id = $1 AND
consumed_at IS NULL AND expires_at > now() RETURNING *`; zero rows means
reject. Rows are purged after one hour.

### sessions

```sql
CREATE TABLE sessions (
  id               uuid PRIMARY KEY,           -- opaque value in the cookie is a different random token
  token_hash       text NOT NULL UNIQUE,
  tenant_id        uuid NOT NULL REFERENCES tenants(id),
  member_id        uuid NOT NULL,
  is_platform_operator boolean NOT NULL DEFAULT false,
  created_at       timestamptz NOT NULL,
  last_seen_at     timestamptz NOT NULL,
  idle_expires_at  timestamptz NOT NULL,
  absolute_expires_at timestamptz NOT NULL,
  revoked_at       timestamptz,
  user_agent_hash  text,
  FOREIGN KEY (tenant_id, member_id) REFERENCES members (tenant_id, id)
);
CREATE INDEX sessions_member ON sessions (tenant_id, member_id);
```

Expiry policy in ADR-0006. Role is read from `members` on every request, not
cached in the session, so a role change takes effect immediately.

### platform_operators

```sql
CREATE TABLE platform_operators (
  id             uuid PRIMARY KEY,
  slack_team_id  text NOT NULL,
  slack_user_id  text NOT NULL,
  display_name   text NOT NULL,
  created_at     timestamptz NOT NULL,
  disabled_at    timestamptz,
  UNIQUE (slack_team_id, slack_user_id)
);
```

Operators are added by a CLI script, never through the dashboard. A login
whose `(team_id, user_id)` matches an enabled operator gets
`sessions.is_platform_operator = true` in addition to its ordinary membership.

### secrets and tenant_keys

```sql
CREATE TABLE tenant_keys (
  tenant_id      uuid PRIMARY KEY REFERENCES tenants(id),
  master_key_id  text NOT NULL,        -- id in the ATLAS_MASTER_KEYS ring
  wrapped_dek    bytea NOT NULL,       -- AES-256-GCM wrapped data-encryption key
  created_at     timestamptz NOT NULL,
  rotated_at     timestamptz
);

CREATE TABLE secrets (
  id             uuid PRIMARY KEY,
  tenant_id      uuid REFERENCES tenants(id),   -- NULL for platform secrets
  kind           text NOT NULL,                 -- 'slack_bot_token','runtime_forwarding_secret','runtime_admin_token','runtime_master_key','model_provider_key','pkce_verifier',...
  key_id         text NOT NULL,                 -- tenant dek id or master key id for platform secrets
  ciphertext     bytea NOT NULL,
  nonce          bytea NOT NULL,
  aad            text NOT NULL,                 -- '<tenant_id>|<kind>|<id>' bound into GCM
  created_at     timestamptz NOT NULL,
  retired_at     timestamptz
);
CREATE INDEX secrets_tenant_kind ON secrets (tenant_id, kind);
```

Secrets are never selected by the generic repository layer; only
`packages/secrets` reads `ciphertext`. See ADR-0007 for rotation.

### runtime_instances

```sql
CREATE TABLE runtime_instances (
  id                     uuid PRIMARY KEY,
  tenant_id              uuid NOT NULL REFERENCES tenants(id) UNIQUE,   -- one runtime per tenant in v1
  provider               text NOT NULL CHECK (provider IN ('fly','kubernetes','railway','fake')),
  provider_service_ref   text,                  -- opaque provider service identifier
  provider_volume_ref    text,
  provider_state         jsonb NOT NULL DEFAULT '{}'::jsonb,  -- step markers for retry-safe provisioning, no secrets
  release                text NOT NULL,          -- image reference incl. digest, e.g. ghcr.io/example/jarvis@sha256:...
  status                 text NOT NULL CHECK (status IN ('requested','provisioning','ready','degraded','stopped','starting','suspended','failed','destroying','destroyed')),
  status_reason          text,
  always_on              boolean NOT NULL DEFAULT false,   -- never idle-stopped (scheduled tasks, heartbeat)
  last_activity_at       timestamptz,                      -- last inbound event or gateway call; drives idle stop
  ingress_url            text,                   -- private URL, e.g. http://runtime-<id>.railway.internal:3002
  resource_class         text NOT NULL,
  region                 text,
  forwarding_secret_ref  uuid NOT NULL,
  admin_token_secret_ref uuid NOT NULL,
  master_key_secret_ref  uuid NOT NULL,
  model_key_secret_ref   uuid,
  last_health_status     text CHECK (last_health_status IN ('ok','unreachable','error')),
  last_health_at         timestamptz,
  last_projection_hash   text,
  last_projection_at     timestamptz,
  provision_attempts     int NOT NULL DEFAULT 0,
  created_at             timestamptz NOT NULL,
  updated_at             timestamptz NOT NULL
);
```

### runtime_service_tokens

Bearer credentials the runtime presents to ATLAS. ATLAS stores hashes only.

```sql
CREATE TABLE runtime_service_tokens (
  id           uuid PRIMARY KEY,
  tenant_id    uuid NOT NULL REFERENCES tenants(id),
  runtime_id   uuid NOT NULL REFERENCES runtime_instances(id),
  token_hash   text NOT NULL UNIQUE,
  created_at   timestamptz NOT NULL,
  expires_at   timestamptz,
  revoked_at   timestamptz
);
CREATE INDEX runtime_service_tokens_runtime ON runtime_service_tokens (tenant_id, runtime_id);
```

Rotation creates a new token, pushes it to the runtime, then revokes the old
one after the runtime confirms (or after a grace window).

### connections

```sql
CREATE TABLE connections (
  id                    uuid PRIMARY KEY,
  tenant_id             uuid NOT NULL REFERENCES tenants(id),
  owner_type            text NOT NULL CHECK (owner_type IN ('tenant','member')),
  owner_member_id       uuid,
  provider              text NOT NULL CHECK (provider IN ('pipedream')),   -- 'mcp' added later
  app_slug              text NOT NULL CHECK (app_slug ~ '^[a-z0-9][a-z0-9_-]{0,99}$'),
  alias                 text NOT NULL,          -- pipedream__<slug> or pipedream__<slug>__m<8hex>
  display_name          text NOT NULL,
  status                text NOT NULL CHECK (status IN ('pending','connected','unhealthy','revoked')),
  external_user_id      text NOT NULL,          -- tenant:<id> or tenant:<id>:member:<id>
  provider_account_id   text,                   -- Pipedream account id (non-secret)
  provider_account_label text,
  authorized_scopes     text[] NOT NULL DEFAULT '{}',
  policy                jsonb NOT NULL DEFAULT '{}'::jsonb,   -- e.g. {"toolMode":"read_only"}
  last_checked_at       timestamptz,
  last_error_stage      text,
  created_by_member_id  uuid NOT NULL,
  created_at            timestamptz NOT NULL,
  updated_at            timestamptz NOT NULL,
  revoked_at            timestamptz,
  CHECK ((owner_type = 'tenant' AND owner_member_id IS NULL) OR (owner_type = 'member' AND owner_member_id IS NOT NULL)),
  FOREIGN KEY (tenant_id, owner_member_id)      REFERENCES members (tenant_id, id),
  FOREIGN KEY (tenant_id, created_by_member_id) REFERENCES members (tenant_id, id)
);
CREATE UNIQUE INDEX connections_alias_live ON connections (tenant_id, alias) WHERE revoked_at IS NULL;
CREATE INDEX connections_owner ON connections (tenant_id, owner_type, owner_member_id);
```

Ownership rule: `owner_type = 'tenant'` rows may be created, modified, or
deleted only by `owner`/`admin`; `owner_type = 'member'` rows only by the
owning member (and revoked by `owner`/`admin`). Personal connections are never
returned in another member's list beyond `app_slug` and `owner` display name.

### slack_event_receipts

Platform-scoped durable deduplication. Written before tenant resolution.

```sql
CREATE TABLE slack_event_receipts (
  event_id       text PRIMARY KEY,               -- Slack event_id (Ev...)
  team_id        text NOT NULL,
  enterprise_id  text,
  api_app_id     text NOT NULL,
  event_type     text NOT NULL,
  received_at    timestamptz NOT NULL,
  retry_num      int NOT NULL DEFAULT 0,
  outcome        text NOT NULL CHECK (outcome IN ('queued','dropped')),
  drop_reason    text,                            -- unknown_team, revoked, suspended, runtime_not_ready, self_echo, unsupported_type
  tenant_id      uuid
);
CREATE INDEX slack_event_receipts_received ON slack_event_receipts (received_at);
```

Retained 30 days, then purged. Contains no message content.

### slack_event_deliveries

Transient queue of forwarded bodies. Contains message content, so retention
is deliberately short (ADR-0002).

```sql
CREATE TABLE slack_event_deliveries (
  id               uuid PRIMARY KEY,
  tenant_id        uuid NOT NULL REFERENCES tenants(id),
  runtime_id       uuid NOT NULL REFERENCES runtime_instances(id),
  event_id         text NOT NULL REFERENCES slack_event_receipts(event_id),
  raw_body         bytea,                          -- byte-exact Slack payload; NULLed on success
  body_sha256      text NOT NULL,
  channel_id       text NOT NULL,
  thread_ts        text,
  sender_slack_user_id text,
  status           text NOT NULL CHECK (status IN ('queued','delivered','failed','expired')),
  attempts         int NOT NULL DEFAULT 0,
  last_error_code  text,
  created_at       timestamptz NOT NULL,
  delivered_at     timestamptz,
  UNIQUE (tenant_id, event_id)
);
CREATE INDEX slack_event_deliveries_status ON slack_event_deliveries (status, created_at);
```

`raw_body` is cleared on successful delivery and the row is purged after 7
days; undelivered bodies expire after 24 hours and the delivery is marked
`expired` with an audit event.

### audit_events

Append-only. The writer accepts only an allow-listed metadata shape per

```sql

  actor_id       text,
```

## Row-level security

Applied to: `members`, `slack_installations`, `sessions`, `runtime_instances`,
`runtime_service_tokens`, `connections`, `provider_external_users`,
`slack_event_deliveries`, `subscriptions`, `audit_events` (tenant rows),
`usage_events`, `secrets` (tenant rows), `tenant_keys`,
`model_provider_scopes`, `credit_ledger`, `credit_balances`,
`reconciliation_runs`.

```sql
ALTER TABLE connections ENABLE ROW LEVEL SECURITY;
ALTER TABLE connections FORCE ROW LEVEL SECURITY;
CREATE POLICY connections_tenant ON connections
  USING (tenant_id = current_setting('app.tenant_id', true)::uuid);
```

Tables that also hold platform rows (`secrets`, `audit_events`) use
`USING (tenant_id IS NULL OR tenant_id = current_setting('app.tenant_id', true)::uuid)`
so platform secrets and platform-level audit entries remain readable without
a tenant setting while tenant rows stay scoped.

Platform code paths (gateway resolution, operator views, provisioning worker
before a tenant context is established) connect through
`withPlatformTransaction`, which sets `app.tenant_id` to the specific tenant
once it is known and otherwise only touches platform tables. There is no
"all tenants" bypass in application code; operator listings iterate with
explicit per-tenant contexts or use a dedicated read-only view that exposes
non-sensitive columns.

## Retention summary

| Data | Retention |
| --- | --- |
| `oauth_states` | 1 hour after expiry |
| `sessions` | deleted at absolute expiry |
| `slack_event_receipts` | 30 days |
| `slack_event_deliveries.raw_body` | cleared on delivery; 24 hours max for failures |
| `audit_events` | 400 days |
| `usage_events` | 400 days (aggregate before purge when billing exists) |
| `credit_ledger` | indefinite (financial record); tenant rows survive deletion in anonymized form |
| tenant data after deletion request | ADR-0013 |
